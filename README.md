# Yoga Posture Classification System

## Project Overview

The Yoga Posture Classification System is an AI-powered application that identifies and classifies yoga poses using Computer Vision and Machine Learning techniques.

The system uses MediaPipe for human pose estimation and extracts body landmarks from images or live webcam feeds. These landmarks are then processed by a trained Machine Learning model to predict the performed yoga posture.

## Objectives

- Detect human body landmarks using AI.
- Classify different yoga poses accurately.
- Support both image upload and live webcam prediction.
- Provide real-time pose recognition.
- Demonstrate practical applications of AI in fitness and healthcare.


## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Scikit-Learn
- Flask

## ✨ Features

- Yoga pose classification from uploaded images.
- Real-time yoga pose detection using webcam.
- Body landmark visualization.
- Machine Learning based pose prediction.
- User-friendly interface.
